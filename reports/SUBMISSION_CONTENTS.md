# Submission contents

Open UrbanCart_Submission.ipynb for the executed original Learnbay skeleton, README.md for setup,
presentation/UrbanCart_Presentation_LLM.pptx for the three-slide presentation, and
reports/CURRENT_EVALUATION.md for measured results and remaining limitations.

The repository includes the supplied data, processed audit outputs, Python application,
evaluation cases and test evidence. Add your own local .env using .env.example to run live.

A portable package is also available at submission/UrbanCart_Submission_Final.zip.
Credentials, virtual environments and runtime databases/indexes are intentionally excluded.
